# Portfolio-v2 deep review, 2026-10-17

Checked against the code and the live site (https://portfolio-v2-gilt-rho-53.vercel.app) in Chrome at 1440 and 390 wide.

## Big problems (design and trust)

1. Docket text is not true on the live demo. The site says it "reads PDFs, emails, photos" and "The AI reads, the code decides". The live Docket uses the rules reader with no AI, and photos are refused. Services also lists Docket under "OpenAI features". A client who uploads a photo sees an error. Files: lib/projects.ts lines 27-40, lib/content.ts line 22.
2. The only visuals are whole-page screenshots shrunk to card size. The text in them can't be read, they look like wireframes, and the type tag and the arrow circle cover parts of them. This is the main reason the site still looks amateur next to studio sites, which show designed mockups and video.
3. The hero shows no work. It is text over blurred colour blobs, grain and a grid, which is the most common template look. The first screen gives no proof. On a phone the top 200px is empty dark space.
4. On phones the header only shows Work and Contact. Services, About and Process can't be reached from the menu because there is no menu button (globals.css line 186).
5. The home page has no person on it. No face, and the name only appears in a small eyebrow. For a freelancer, trust comes from seeing who you hire.
6. There is no way to check Bilal outside the site. No GitHub profile link, no Upwork or LinkedIn link, and contact is email only.

## Bugs confirmed on the live site

7. Card hover zoom never works. The reveal rule `.js .reveal-img.is-in img { transform: scale(1) }` has the same specificity as the hover rule and comes later, so it wins. Measured transform on hover: identity.
8. The case study screenshot frame loses its shadow. The clip-path reveal also clips the box-shadow.
9. The tools strip jumps 28px every loop. Period 2492px vs half-width 2464px, caused by the flex gap.
10. Work table preview: the first hover shows an empty box for about 1.1s because it loads the raw 1.2MB PNG instead of an optimised image. On mouse leave the image is removed at once, so the fade-out is an empty box.
11. The Work page shows no images on phones. The preview is hover-only, so it is a plain text list.
12. Magenta text on the dark header is 4.1:1 contrast, below the 4.5:1 AA minimum (the current-page nav link).
13. With reduced motion on, the tools strip shows every tool twice.
14. The whole page fades in from opacity 0 and the hero words start hidden, so first paint waits for the animation. If the reveal script fails after the `js` class is set, content below the hero stays invisible.

## Smaller

15. No robots.txt or sitemap.xml (both 404). The site is on a vercel.app address. The share image is a raw screenshot, not a designed card. Services, About, Process and Contact have no description of their own.
16. Live demo and GitHub links open in the same tab. The footer has no Contact page link.
